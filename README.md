- **65 questions** · 90 minutes · pass line = **700/1000**

- **Question types:** Single select and SELECT TWO (multi-select)

## High-Priority Topics (from the Official CLF-C02 Exam Guide)

These topics appear across all four domains and carry significant weight per the [official AWS exam guide](https://aws.amazon.com/certification/certified-cloud-practitioner/):

- **Shared Responsibility Model** — know the shift by service (Amazon EC2 vs Amazon RDS vs AWS Lambda)
- **Well-Architected Framework** — all 6 pillars and their trigger phrases (OSRPCS mnemonic)
- **AWS IAM** — Users, Groups, Roles, Policies, Root User, IAM Identity Center
- **Amazon S3** — storage classes, versioning, lifecycle policies
- **AWS Cloud Adoption Framework** — all 6 perspectives (BGPPSO mnemonic)
- **AWS WAF** — blocks SQL injection and cross-site scripting (XSS)
- **Networking** — Amazon VPC, subnets, Internet Gateway, NAT Gateway, Security Groups vs Network ACLs
- **Hybrid connectivity** — AWS Site-to-Site VPN vs AWS Direct Connect, Virtual Private Gateway, Customer Gateway
- **7 Rs migration strategies**
- **Billing tools** — AWS Pricing Calculator vs AWS Cost Explorer vs AWS Budgets vs AWS Cost and Usage Report

## Study Tips

1. **Read every answer choice before clicking** — the real exam options are longer than practice exams
2. **For SELECT TWO questions** — eliminate the two obviously wrong answers first, then choose from what's left
3. **Use pen and paper** at the testing center for VPC/subnet diagrams
4. **Flag and review** — finish all questions, then go back to flagged ones
5. **Use all the time** — don't rush
6. **Full service names** — the real exam writes "Amazon Simple Notification Service" not "SNS." Know both.
