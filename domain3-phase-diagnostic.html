Exam traps from your quiz — VPC and Networking: VPC instances communicating with on-premises remote network = Site-to-Site VPN (encrypted tunnel over internet). Direct Connect = dedicated private line, higher bandwidth/lower latency but not the default answer for basic VPC connectivity. Internet Gateway = allows VPC resources to communicate with the internet. Required for any public subnet. Security Groups = stateful, instance level. NACLs = stateless, subnet level.
Exam traps — Load Balancers: ALB = Layer 7, HTTP/HTTPS only. Best choice for web applications. Supports path-based routing, host-based routing, fixed responses, WebSocket, and multiple ports per instance. NLB = Layer 4, TCP/UDP. For extreme performance or static IP requirements. CLB = legacy. Fewer features. "HTTP and HTTPS Load Balancer" is NOT a real AWS service name. Minimum 2 AZs for ALB high availability.
Exam traps — Service definitions (commonly confused): CloudFront = CDN, speeds up static and dynamic content distribution via edge locations. ELB = distributes incoming traffic across multiple targets (EC2, containers, IPs, Lambda). Route 53 = DNS service — translates domain names to IPs. VPC = launches resources into a virtual network you define. Global Accelerator = improves global app availability and performance via AWS backbone network. These four appear as wrong answers for each other — know all definitions cold.
Exam traps — Storage and CloudWatch: EBS = recommended for database storage on EC2 — persistent, consistent IOPS. Instance store = temporary, lost on stop. CloudWatch Logs = stores and accesses logs from EC2, Route 53, Lambda. NOT CloudTrail (which records API calls). CloudWatch Alarms = can stop/start/terminate EC2 instances based on metric thresholds. S3 Lifecycle = auto-transition objects between storage classes over time to reduce cost. Consolidated billing = FREE. No extra charge.
