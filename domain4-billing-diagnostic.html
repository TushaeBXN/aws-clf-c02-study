4.1 · Compute Purchasing Options

On-DemandNo commitment, pay per second/hour. Best for short-term or unpredictable workloads.
Reserved (Standard)1 or 3 year commitment, up to 72% off. Locked to instance family/Region/OS. Best for steady-state.
Reserved (Convertible)1 or 3 year commitment, smaller discount. CAN change instance family, OS, or scope mid-term.
Spot InstancesUp to 90% off. Can be INTERRUPTED by AWS with 2-min warning. For fault-tolerant, flexible workloads only.
Compute Savings Plans1 or 3 year hourly spend commitment. Applies to EC2 + Fargate + Lambda regardless of Region/OS/family.
EC2 Instance Savings1 or 3 year commit. Applies to specific EC2 instance family in a Region only. Higher discount than Compute.
Dedicated InstancesHardware isolated from OTHER customers. No host-level visibility. For compliance isolation requirements.
Dedicated HostsPhysical server FULLY dedicated to you. Gives socket/core visibility. Required for BYOL per-core licensing.
Capacity ReservationsReserve capacity in a SPECIFIC AZ. No commitment term needed. No automatic discount — pay On-Demand rate.

4.1 · Storage Tiers & Data Transfer

S3 StandardFrequently accessed. No retrieval fee. Lowest latency.
S3 Standard-IAInfrequent access. Has per-GB retrieval fee. Lower storage cost than Standard.
S3 GlacierArchival. Very low storage cost. Retrieval takes minutes to hours.
S3 Intelligent-TierAuto-moves objects based on access. No retrieval fees.
Data IN (ingress)Data transferred INTO AWS from internet = FREE.
Data OUT (egress)Data transferred OUT to internet = CHARGED.
Cross-RegionData transferred between Regions = CHARGED.
Same-Region AZsData between AZs in same Region = CHARGED (small fee).
Same AZData within same AZ = FREE.
Spot billingUser stops = pay exact seconds used. AWS interrupts = partial hour FREE.

4.2 · Cost Management Tools

AWS Pricing CalculatorPRE-deployment cost estimation. Build architectural estimates before launching anything.
AWS Cost ExplorerPOST-deployment visualization. Charts historical spend by service, Region, tag. Includes forecasting and rightsizing recommendations.
AWS BudgetsSet custom cost/usage thresholds. Sends alerts via email or SNS when actual or forecasted spend hits threshold.
Cost & Usage ReportMost detailed billing data available. Every resource, tag, and charge in CSV/Parquet. Load into Athena/Redshift for analysis.
Cost Allocation TagsMetadata labels (key:value) on resources. Must be ACTIVATED in Management Account billing console to appear in reports.
AWS Pricing APIsProgrammatic access to current service pricing data across all Regions.

4.2 · AWS Organizations & Billing

Consolidated billingSingle invoice for all member accounts. Paid by the Management Account (formerly master account).
Volume discountsCombined usage across ALL accounts in the org to hit lower pricing tiers faster (e.g., S3 storage).
Free TierShared across the org — ONE set of Free Tier limits for the entire organization, not multiplied per account.
Cost Allocation TagsMust be activated from the Management Account billing console for org-wide aggregation.
SCPsService Control Policies — restrict what member accounts are ALLOWED to do. Can block expensive instance types. NOT a billing tool but used for cost governance.
No extra chargeAWS Organizations itself is free. Consolidated billing feature is free.

4.3 · AWS Support Plans

Basic (free)Documentation, forums, billing cases only. No technical support tickets. Trusted Advisor core checks.
DeveloperEmail access to support during business hours. 1 primary contact. For development/testing.
Business24/7 phone + chat + email. Multiple contacts. Trusted Advisor full checks. 1-hour SLA for urgent. No TAM.
Enterprise On-Ramp24/7 support. POOLED TAM team. 30-min SLA for critical. Architectural guidance.
Enterprise24/7 support. DEDICATED TAM. 15-min SLA for critical. Support Concierge for billing. Highest tier.

4.3 · Support Tools & Resources

Trusted AdvisorAutomated inspection across 5 pillars: Cost, Security, Performance, Fault Tolerance, Service Limits. Real-time recommendations.
Health DashboardReal-time AWS service availability and outage status by Region. Personalized view of events affecting YOUR resources.
Trust & Safety TeamReport ABUSE of AWS resources — spam, port scanning, malware, DDoS attacks originating from AWS IPs.
AWS MarketplaceBuy third-party software (firewalls, SaaS tools, ML models). Billed on your AWS invoice.
Professional ServicesAWS expert team for hands-on project execution — migrations, transformations. Engaged as a consulting team.
Support ConciergeEnterprise plan only. Billing and account specialist. Handles invoice questions, credits, non-technical account queries.
AWS re:PostCommunity-driven, AWS-moderated Q&A forum for technical AWS questions.
Prescriptive GuidanceCurated AWS-authored reference architectures, migration patterns, and best-practice guides.
Knowledge CenterAWS-written answers to frequently asked questions about AWS services.
Pricing model confusables: Dedicated Hosts = physical server dedicated to you, BYOL/per-core licensing. Dedicated Instances = hardware isolated from other customers, no host visibility. Compute Savings Plans = applies to EC2 + Fargate + Lambda, any Region/OS/family. EC2 Instance Savings Plans = EC2 only, specific instance family and Region. Standard RIs = locked configuration, biggest discount. Convertible RIs = can change family/OS, smaller discount. Spot = cheapest but interruptible. Capacity Reservations = guaranteed capacity, no discount, no commitment.
Cost tool confusables: AWS Pricing Calculator = BEFORE deployment (estimates future spend). AWS Cost Explorer = AFTER deployment (visualizes historical + forecasted spend, rightsizing). AWS Budgets = ALERT tool (sends email/SNS when threshold is hit). Cost & Usage Report = MOST DETAILED raw billing data (CSV, every resource and tag). These four are tested against each other constantly — know the primary job of each.
Support plan confusables: Basic = free, billing cases only, no technical support. Developer = business hours email only. Business = 24/7 phone/chat, MINIMUM for around-the-clock technical support. Enterprise On-Ramp = pooled TAM, 30-min critical SLA. Enterprise = dedicated TAM, 15-min critical SLA, Support Concierge. Trust & Safety = report ABUSE of AWS resources (not general support). AWS Marketplace = buy third-party software, billed on AWS invoice. Professional Services = AWS experts hired for complex project work.
