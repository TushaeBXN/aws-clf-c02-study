Tips from People Who Passed

→
Read every answer choice before clicking. The real exam options are longer than practice exams.
→
For SELECT TWO questions, eliminate the two obviously wrong answers first, then choose from what's left.
→
Use pen and paper at the testing center for Amazon VPC and subnet diagrams.
→
Flag and review. Finish all 65 first, then go back to anything flagged. Use all 90 minutes.
→
Full service names on the real exam. It says "Amazon Simple Notification Service" not "SNS." Know both.
→
First instinct is usually right. Don't talk yourself out of your answer once you've read all the choices.
→
Half the questions are straightforward. The other half require reading carefully 2-3 times. Budget your time.

How to Set This Up on GitHub Pages

1
Fork or create a new repo on GitHub. Name it something like aws-clf-c02-study.
2
Upload all the HTML files into the root of the repo. Make sure index.html is in the root.
3
Go to Settings → Pages. Set source to main branch, / (root) folder. Click Save.
4
Wait 1-2 minutes. Your site will be live at https://yourusername.github.io/aws-clf-c02-study/
5
Share the link with your cohort. Every file is accessible — no server needed.
